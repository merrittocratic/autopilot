# X Engaged Accounts — Manual Engagement History

Accounts where @Merrittocratic has prior engagement history (replies,
likes, or quote tweets from the X app). The X API blocks reply and
quote-tweet calls to "cold" accounts — Steve must manually seed
engagement first before automated replies work.

This file is the canonical source of truth. The Mac Mini reads it from
`$HOME/autopilot/openclaw-scripts/x-engaged-accounts.md` (moved from
`~/.openclaw/workspace/x-engaged-accounts.md` as part of the single-
source-of-truth migration).

## Format

One handle per line, with or without leading `@`. Comments and blank
lines are ignored.
